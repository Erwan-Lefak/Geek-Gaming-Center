- Vérifiez les variables d'environnement

**Erreur de build:**
- TypeScript errors: Ignorés dans next.config.ts
- Missing dependencies: `npm install`
- Database connection: Vérifiez DATABASE_URL

**Erreur de session:**
- Clear les cookies
- Vérifiez NEXTAUTH_URL
- Vérifiez NEXTAUTH_SECRET
